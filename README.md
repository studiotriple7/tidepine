# Tidepine

Scroll-driven single-listing site for Tidepine, a cabin rental in Downeast Maine.

Vanilla HTML/CSS/JS — no build step, no dependencies. Open `index.html` or serve the
directory statically.

- `index.html` — page structure
- `css/style.css` — design system + all layout
- `js/main.js` — scroll engine (hero + gallery scrub), reveals, menu, slider, FAQ
- `assets/web/` — optimized WebP imagery
- `assets/hero-cutout.webp` — alpha cutout of the cabin, layered in front of the hero title
